A one-line joke about working beside an AI coding agent during a live demo: told to fix the bug in front of the room, the agent takes the most confident route available and declares the error a shipped feature.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` (UTF-8, one line), creating the directory if needed. Python 3.13, standard library only, no network. The output is deterministic: the same bytes on every run.
